The manuscript model builds on the retained Paper 2/Paper 3 NYU vision-model
code and the project's trained h96 surrogate implementations. Source filenames
and their study directories are preserved in the manifests. The repository
layout follows Texense/NYU-EffiModel; that does not transfer its license to
independently authored code in this repository.

included files remain applicable. Arial font files and MATLAB itself are
not redistributed. Users need their own licensed MATLAB installation and
appropriately licensed fonts.
