# Reproduction validation

## Scope and environment

The 44 root Live Scripts were executed using MATLAB R2025b on macOS Apple
Silicon from the self-contained repository copy. `validation.json` records
the exact MATLAB version, installed toolboxes, script hashes and execution
results. The tested collection consists of 23 main-figure entry points,
11 current supplementary entry points (S1 has two scripts), and 10 historical
alternatives, including the older ODE/library S1/S2 study. The main identifiers
follow `main_01.pdf` through `main_05.pdf` and the author-approved `main_06.key`.

This is an execution check of the plotting pipeline, not a new validation of
the original trained models or a rerun of the HPC simulations. Installed
toolboxes are recorded for environment provenance, not asserted to be the
minimal dependency set. Current primary PDFs and supplementary PDFs were
rendered and visually inspected, including the large multi-panel layouts.

## Numerical checks

`Utils/verify_published_numbers.m` checks regenerated graph objects and tables:

- Main 1B: exactly 615 plotted measurements, comprising 290 CG, 320 accelerated
  DNN and five 500-second SNN trials. All timing values match the retained
  published CSV. Hidden scatter handles are included with `findall`.
- Main 1C: exactly 28,000 plotted CG/DNN pixel pairs. Seventy stimulus
  conditions each contribute 400 displayed pixels, not one dot per condition.
- Main 1F/G: all six heatmap arrays match the retained source FIG exactly.
- Main 4B: 4,800 singular values in each condition; small-singular-value counts
  2,981 and 1,792, complementary effective ranks 1,819 and 3,008, and
  near-zero-real-part eigenvalue counts 2,988 and 1,806. The control flattens
  L4 smoothing only and leaves L6 unchanged.
- Main 6D: all 22 common-input peak times are recomputed from retained
  trajectories and agree with the published peak table. Initial perturbations
  and the HC amplitude of 1 sp/s are checked by the Live Script.

Suppl. S2 uses the thirteen original paired cold-start TSVs: median
per-iteration and total-runtime speed ratios are 96.7316405 and 77.1761417,
respectively. These are historical results, separate from Main 1B.

## Portability adaptations

Original plotting calculations, measured values, colors and relative layouts
are retained. Absolute research paths are replaced by repository-relative
input/workspace paths. Inputs are copied into the ignored `Outputs/workspace`
before plotting so scripts do not modify the immutable `Data` directory.
Historical source names are mapped to current main-panel export names.

Main 1F/G and the historical ODE/library S2 use uniformly quarter-sized
physical coordinates, fonts and line widths during export. This avoids a
macOS large-canvas clipping/blank-export problem; data and relative geometry
are unchanged. These are vector PDFs. Other panel exports retain the source
format. The selected data variables for Suppl. S10 and the selected columns
for historical Figure 5E are retained losslessly, without numerical rounding.
Historical Figure 5E checks the selected grid indices before plotting.

`MANIFEST.json` records code, reference assemblies and data SHA-256 hashes.
`Data/manifest.json` covers numerical inputs, and `Data/REVISION` controls the
working-copy refresh. `python3 Utils/verify_manifest.py` verifies a checkout.

## Boundaries

The original Keynote artwork, manual schematics and assembly are retained
in `Reference`, but not claimed to be generated by MATLAB. This includes
the conceptual drawings in Main 1A/2A and the manual part of Main 4C.
Run the Live Scripts for the numerical panels; consult the assemblies for
the final manuscript composition.

Retained FIG inputs contain MATLAB data/graphics objects, not screenshot
substitutes. Their reuse matches the source plotting workflow. Some upstream
raw SNN spike histories were previously deleted at the author's request.
The archived HPC sources have not been re-executed in this packaging task,
and are not a portable one-command cluster installation. See
`MFpVLDEComput/README.md` and its explicit unavailable-historical-source list.

Main 1B preserves the original timing scopes: CG/DNN iteration and residual
checks versus the complete fixed-duration SNN driver, with later variability
analysis excluded. Its label does not establish equal error guarantees between
deterministic update residuals and stochastic estimation uncertainty. The
existing representative-reuse approximation in the accelerated DNN is unchanged.
